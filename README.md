## 📌 Giới thiệu tóm tắt (Executive Summary)

> **"Phát triển phần mềm với tư duy kiến trúc hệ thống hoàn chỉnh — từ trải nghiệm người dùng mượt mà trên Mobile & Web, giải pháp Backend mạnh mẽ, đến chuẩn mực kiểm thử tự động (Automation QA) bảo đảm độ tin cậy tuyệt đối."**

Tôi là lập trình viên định hướng **Full-Stack & Mobile Development** kết hợp nền tảng vững chắc về **Kiểm thử phần mềm tự động (Automated Testing)**. Điểm mạnh nổi bật của tôi là khả năng phát triển các **hệ sinh thái ứng dụng kép (Dual-Side System: Customer & Admin)**, làm việc trên cả nền tảng web doanh nghiệp (.NET 10, ASP.NET Core MVC, Docker, SQL Server) và ứng dụng di động đa nền tảng (Flutter, Firebase).

### 💡 Năng lực cốt lõi
- ⚡ **Full-Stack Web Engineering:** Xây dựng hệ thống web thương mại điện tử chuyên sâu với **.NET 10**, áp dụng Clean Architecture, thuật toán gợi ý dữ liệu (Apriori Algorithm), phân quyền đa tầng (RBAC) và realtime SignalR.
- 📱 **Mobile App Development:** Thiết kế và phát triển ứng dụng di động **Flutter** đa nền tảng, tích hợp dịch vụ Firebase thời gian thực, quản lý trạng thái khoa học và giao diện chuẩn UI/UX.
- 🧪 **Test Automation & QA:** Xây dựng framework kiểm thử tự động UI/E2E với **Selenium WebDriver (C# / NUnit)**, áp dụng mô hình **Page Object Model (POM)** và **Data-Driven Testing** với bộ dữ liệu hơn **2,100+ Test Cases**.
